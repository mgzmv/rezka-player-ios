# 🎬 Rezka Player для iOS (iPhone & iPad)

Нативное iOS-приложение (SwiftUI, iOS 17+) для просмотра и скачивания фильмов, сериалов, мультфильмов и аниме с `hdrezka.name` (и любых зеркал HDRezka).

## ✨ Возможности
- **Полный каталог и поиск:** Категории (Все, Фильмы, Сериалы, Мультфильмы, Аниме), фильтры (Новинки, Популярное, Смотрят), поиск по названию и открытие прямых ссылок HDRezka (включая `#t:105-s:1-e:9`).
- **Обход защиты Anubis PoW:** Автоматическое решение криптографической задачи SHA-256 Proof-of-Work прямо на устройстве без сторонних серверов.
- **Дешифратор потоков HDRezka:** Нативная очистка мусорных токенов и Base64-декодирование прямых потоков `.mp4` во всех качествах (`360p`, `480p`, `720p`, `1080p`, `1080p Ultra`).
- **Продвинутый видеоплеер:**
  - Выбор любой студии озвучки, сезона и серии.
  - Переключение качества видео «на лету» с сохранением текущей секунды.
  - Внешние субтитры (WebVTT парсер и рендеринг поверх видео).
  - Картинка в картинке (PiP), AirPlay, запоминание позиции просмотра и отметка просмотренных серий.
- **Фоновые загрузки для офлайн-просмотра:**
  - Скачивание `.mp4` в фоновом режиме (`URLSession` background transfer) с паузой, докачкой и автообновлением истекших ссылок.
  - Доступ к скачанным файлам в приложении **«Файлы»** на iOS и экспорт через меню «Поделиться».

## 📲 Установка через SideStore
1. Перейдите в раздел **[Releases](../../releases/latest)** этого репозитория.
2. Скачайте файл **`RezkaPlayer.ipa`** на iPhone или iPad.
3. Откройте **SideStore** → вкладка **My Apps** → нажмите **`+`** и выберите `RezkaPlayer.ipa`.
